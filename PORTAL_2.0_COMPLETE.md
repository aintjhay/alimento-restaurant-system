## 🚀 Getting Started

### Start the System
```powershell
# Terminal 1 - Backend
cd backend
npm start
# Running on http://localhost:5000

# Terminal 2 - Frontend  
cd frontend
npm start
# Running on http://localhost:3000
```

### Access the Portal
```
Main Menu:        http://localhost:3000/portal
Order History:    http://localhost:3000/portal/orders
Favorites:        http://localhost:3000/portal/favorites
Login:            http://localhost:3000/portal/login
Checkout:         http://localhost:3000/portal/checkout
```
